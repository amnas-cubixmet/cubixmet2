# Cubixmet venture hero images

Place the generated optimized PNG at:

`public/images/ventures/tech-hero.png`

The Tech venture page loads it through the Next.js image component. Until the PNG exists, a fallback image from `public/images/heroProjects/workspace.png` is displayed.

Target asset: business/software development team collaborating on dashboards and applications.
Suggested dimensions: approximately 1080 × 810 px (4:3); PNG optimized for web.
