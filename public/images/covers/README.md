# Portfolio cover images
Default SVG illustrations live in products/ and tools/ subfolders.
These are illustrative cover designs, not screenshots of the actual products.

To replace one with a real screenshot, upload WebP/JPG/PNG to public/images/
and edit its coverImage field in data/products.ts or data/freeTools.ts.

On homepage Portfolio and dedicated /products and /tools pages:
video plays when available; otherwise the cover remains visible.
A missing/broken image falls back to the original graphic behind it.
